# AdvancedResumeAnalyzer


##  Project Description  
AdvancedResumeAnalyzer is an intelligent resume screening system that automates candidate evaluation using Azure AI services. It extracts key information from resumes, analyzes skills and experience using OpenAI, and generates structured feedback - helping recruiters identify top talent faster while giving candidates actionable insights to improve their resumes.

---

##  Key Features  
- **Smart Parsing**: Accurately extracts text from resumes (PDF/DOCX) using Azure Form Recognizer  
- **AI Analysis**: Scores resumes (0-100) and identifies skill gaps using OpenAI GPT-4  
- **Instant Feedback**: Provides personalized improvement suggestions  
- **Serverless Architecture**: Cost-efficient processing via Azure Functions  
- **Bias Reduction**: Focuses on skills rather than demographics  

##  Tech Stack  
- **Backend**: Azure Functions (Python)  
- **AI Services**: Azure Form Recognizer + OpenAI  
- **Database**: Azure SQL (Stores analysis results)  
- **Frontend**: Streamlit (Hosted on Azure App Service)
